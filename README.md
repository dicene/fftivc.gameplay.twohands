# fftivc.gameplay.twohands

## Functionality

This mod enables equipping items in both hands, regardless of having Doublehand, like the PSX version of FFT supports. Using a two-handed weapon will still block both hand slots.

## Usage

- Ensure that you have [Reloaded-II](https://github.com/Reloaded-Project/Reloaded-II) installed and have registered the game FFT - The Ivalice Chronicles itself in Reloaded-II. (Quick Start guide for Reloaded-II can be found here: [Quick Start](https://reloaded-project.github.io/Reloaded-II/QuickStart/))
- Drop the .7z file into Reloaded-II, then enable it.
- Select the mod in Reloaded II and Configure Mod to choose what options you want
